## Codebase Patterns
- AppThemeBinding markup extension cannot be used as `<Color>` element content in ResourceDictionary (XamlC XC0040). Must use inline in `Setter Value="{AppThemeBinding Light=..., Dark=...}"` instead.
- MAUI XAML Color resources can only hold static color values (hex, named colors). Theme-aware colors go in Style setters.
- Static base colors (White, Black, Gray100..Gray950, Primary/Dark) go in Colors.xaml. Themed styles go in Styles.xaml.
